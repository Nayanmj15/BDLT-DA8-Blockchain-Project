# Blockchain and Digital Identity Management System

## Project Overview
This project contains two blockchain-related implementations developed
for the Blockchain and Distributed Ledger Technology Lab.

## 1. Digital Certificate Verification
- Language: Python
- Certificate registration and search
- Blockchain display and hash verification
- Tamper detection

## 2. Digital Identity Management
- Language: Solidity
- Smart contract: DigitalIdentity
- Wallet-based user registration
- Duplicate-registration prevention
- User information retrieval

## Technologies Used
- Python
- Solidity
- SHA-256
- Remix IDE
- Remix VM (Cancun)
